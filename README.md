# Jay's Portfolio

A personal portfolio website showcasing my work as a Creative Designer & Developer.

## Overview

This repository contains the source code for my personal portfolio website, featuring a modern, interactive, and responsive design.

**Website:** [jay-sukheja1.github.io](https://jay-sukheja1.github.io/)

### Features

- **Modern Design:** Clean, beautiful aesthetics with smooth animations and hover effects.
- **Responsive Layout:** Works seamlessly across desktops, tablets, and mobile devices.
- **Interactive UI:** Custom cursor that follows the user's mouse movements and 3D tilt effects on project cards for an engaging user experience.
- **Sections:**
  - `Home`: Introduction and hero section.
  - `Work`: Showcase of my projects and case studies.
  - `Skills`: Overview of my technical and design skills.
  - `Resume`: My professional experience and background.

## Technology Stack

- **HTML5:** Semantic structure and content.
- **CSS3:** Vanilla CSS for styling, animations, layout, and responsive design.
- **JavaScript:** Interactivity, custom cursor, tilt card logic, and smooth scrolling.

## Project Structure

- `index.html`: The main landing page.
- `work.html`: Portfolio projects page.
- `resume.html`: Resume page.
- `css/`: Contains all stylesheets.
- `js/`: JavaScript files for interactivity.
- `resources/`: Images, icons, and other assets.
